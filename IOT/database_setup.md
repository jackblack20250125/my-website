# 🏫 路竹高中 IOT 設備盤點系統 - 讀寫分離架構說明

為了兼顧「**前端極速載入**」與「**高規格資訊安全 (不洩漏簽名檔)**」，本系統採用了純原生的 Google Sheets 實體資料庫讀寫分離 (Read/Write Replica) 架構。

## 💡 為什麼要這樣設計？

1. **GAS (Google Apps Script) 執行很慢**：使用標準 Web App API 讀取試算表，至少會有 2~3 秒的冷啟動延遲。
2. **直接公開主會外洩機密**：如果把含有簽名與敏感資訊的主試算表點擊「公開共用」，將會有嚴重的資安隱患。
3. **終極解決方案**：透過 `IMPORTRANGE` 單向同步資料到「公開分身表」，並使用 Google Visualization API (Gviz) 高速讀取，速度提升至 100 毫秒！

---

## 🏗️ 系統架構圖

```text
[ 前端展示頁面 - IOT/index.html ] 
    │ (使用 Gviz API 高速讀取，無權寫入)
    ▼
[ 公開分身試算表 (Read Replica) ] 
    │ (設定為：知道連結的人可檢視。只包含前14欄公開資料)
    ▲
    │ (單向同步：IMPORTRANGE)
    │
[ 私密主試算表 (Write Master) ]  ◀─── [ 簽名頁面 - IOT/signature.html ]
      (不對外公開，包含完整簽名資料)      (透過 GAS Web App POST 寫入私密表格)
```

---

## 🛠️ 部署操作步驟

如果你需要重新建立這個架構，請依照以下步驟進行：

### 第一步：建立分身表 (Replica)
1. 在 Google 雲端硬碟建立一個**全新的空白 Google 試算表**。
2. 建立兩個工作表 (Tabs)，分別命名為 `設定` 與 `物聯網IoT設備盤點調查表`。

### 第二步：設定唯讀單向同步
1. 在新檔案的 `設定` 表格 **A1** 儲存格，填入公式：
   ```excel
   =IMPORTRANGE("你原本含簽名的秘密試算表ID", "'設定'!A:Z")
   ```
2. 在新檔案的 `物聯網IoT設備盤點調查表` 表格 **A1** 儲存格，填入公式 *(這裡只引入 A 到 N 欄，徹底截斷後方的機密簽名欄位)*：
   ```excel
   =IMPORTRANGE("你原本含簽名的秘密試算表ID", "'物聯網IoT設備盤點調查表'!A:N")
   ```
3. *第一次輸入公式時會出現 `#REF!` 錯誤，請將滑鼠移至儲存格上，點擊「允許存取」來連接這兩份表格。*

### 第三步：公開分身表
1. 點擊這份「新分身試算表」右上角的【共用】按鈕。
2. 將「一般存取權」改為「**知道連結的人 (檢視者)**」。

### 第四步：綁定至前端頁面
1. 複製這份「新分身試算表」的 URL 中的 ID 字串。
2. 打開 `IOT/index.html` 編輯。
3. 找到大約第 900 行附近的程式碼，將 `SHEET_ID` 替換為新 ID：
   ```javascript
   const SHEET_ID = '貼上你剛剛建立的新分身試算表ID'; 
   ```

大功告成！前端現在能如閃電般載入盤點單位，而且沒有任何人能從中挖出受保護的實體簽名檔！
